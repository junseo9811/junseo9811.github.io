Selected projects

Course projects completed in Spring 2026.

Insurance Charge Prediction

Machine Learning Fundamentals · Spring 2026

Explored tabular insurance charge prediction under an asymmetric loss function using LightGBM, CatBoost, and a PyTorch MLP.

  • Implemented quantile-regression ensembles, feature engineering, cross-validation, and model blending.
  • Analyzed distribution shift and validation leakage to examine the reliability of model evaluation.
  • Reported a held-out penalized error of approximately 1,735 in the project’s internal validation.

Python · LightGBM · CatBoost · PyTorch · Quantile regression · Ensemble methods

Java · Object-oriented programming · Strategy Pattern · File-based data persistence

Streamflow Modeling with LSTM and SWAT

Engineering Project · Spring 2026

Compared data-driven and physics-based approaches to watershed streamflow prediction.

  • Applied an Optuna-tuned LSTM and calibrated a SWAT hydrological model.
  • The LSTM achieved R² = 0.71 and NSE = 0.69 in the course project’s evaluation.
  • Compared data-driven and process-based simulations, analyzing prediction errors and limitations in the underlying data.

Python · LSTM · Optuna · SWAT · Streamflow prediction
